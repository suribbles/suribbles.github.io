Game of Traitors - BhaktiSuri Diwali Party

To host: upload everything in this folder to any static web host, keeping
index.html, style.css, player.js and the assets folder together.
Netlify Drop, GitHub Pages, Cloudflare Pages or your own server all work.
Opening index.html from a web address works best; fonts load from Google Fonts.

To present: click, Space or the arrow keys move forward; Left goes back.
Slide 1: click the play button for the promo; "Close video" returns to the slide.
Slide 14: click any letter to open it; click again or press a key to close it.
F is full screen. On a phone, swipe. Link to a slide with #slide-12.
